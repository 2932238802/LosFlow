## 命名约定

- 文件名：`N_短标题.md`，`N` 按实际序列递增（不看日期，看目录里已有的最大编号 +1）。
- 同一目录内编号唯一，改主题不改编号；作废保留文件、在状态里写「作废」。
- 每份文件头部用同一张表：编号 / 日期 / 项目 / 类型 / 状态 / 提出 / 涉及文件，末尾写「变更记录」。
